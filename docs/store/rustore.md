# Публикация в RuStore

RuStore (и Google Play) ставят приложение через «сессионную» установку — для таких приложений
Android не включает «Ограниченные настройки», и друзьям не придётся ничего разрешать вручную.

## Что нужно решить до первой загрузки

1. **Название приложения** и **идентификатор пакета** (сейчас временный `app.budget.budget_app`).
   После первой публикации идентификатор менять нельзя.
2. **Ключ подписи** уже создан: `D:\dev\keys\budget-release.jks` и `D:\dev\keys\key.properties`.
   **Сохраните оба файла в надёжном месте (например, в менеджере паролей и на флешке).**
   Без них нельзя выпустить обновление приложения в магазине.
3. **Адрес почты** для связи — его просят RuStore и политика конфиденциальности.

> Важно: магазинная версия подписана другим ключом, чем APK, которые стоят сейчас на телефонах.
> Поверх них она не установится: сначала сделайте резервную копию в приложении, удалите его,
> установите из RuStore и восстановите копию.

## Сборка для магазина

```powershell
.\tool\build_store.ps1
```

Результат: `build\app\outputs\bundle\release\app-release.aab` (для загрузки) и
`build\app\outputs\flutter-apk\app-release.apk`.

## Шаги в RuStore Консоли (console.rustore.ru)

1. Войти через VK ID, создать аккаунт разработчика (физическое лицо или самозанятый).
2. «Создать приложение» → тип «Приложение», категория **«Финансы»**.
3. Загрузить AAB, заполнить карточку (тексты ниже), скриншоты 1080×2400 (4–8 штук),
   иконку 512×512 (`branding/icon_512_square.png`).
4. Политика конфиденциальности — ссылка на опубликованный текст `privacy_policy_ru.md`
   (например, на GitHub Pages).
5. Отправить на модерацию (обычно 1–3 рабочих дня).

## Карточка приложения

**Краткое описание (до 80 символов):**
Учёт трат без ручного ввода: Alipay, WeChat, банки России и Казахстана

**Полное описание:**
Бюджет записывает траты сам: читает экран оплаты Alipay, уведомления WeChat Pay, уведомления и
SMS банков России и Казахстана — и раскладывает их по категориям, которые запоминает.

• Лимит на день из месячного бюджета, остаток и прогноз «на сколько хватит денег»
• Календарь трат, графики, поиск по операциям
• Делёж счёта с друзьями и учёт долгов, в том числе в другой валюте
• Переводы между своими счетами не считаются тратами
• Цели накоплений, регулярные платежи с напоминаниями
• Несколько валют с автоматическими курсами
• Зашифрованная резервная копия в вашем облаке, блокировка PIN-кодом и отпечатком
• Русский, English, 中文, Қазақша

Без регистрации, рекламы и сервера: данные хранятся только на телефоне в зашифрованном виде.

## Объяснение для модерации (доступ к специальным возможностям и уведомлениям)

Приложение использует службу специальных возможностей не для помощи людям с ограничениями, а для
автоматической записи расходов: оно читает текст экранов результата оплаты и списков операций
только в Alipay, WeChat и приложениях банков (список пакетов задан в конфигурации службы) и
сохраняет найденные операции (сумма, дата, получатель) на устройстве. Служба ничего не нажимает
и не читает поля паролей. Перед включением приложение показывает экран с объяснением и просит
согласия. Доступ к уведомлениям используется для уведомлений о платежах тех же приложений и SMS
банков; остальные уведомления сразу отбрасываются. Данные не передаются за пределы устройства.
